# Global Shipment Control Tower (demo)

A demo of a shipment control tower with sample data, hosted as a static page.

- `index.html` is the whole app.
- `users.js` is the list of people who can sign in (email, role, hashed password).
- `make-users.html` creates `users.js`. Open it on your own computer, not from the website.

This is a demo with sample data. The sign-in is a gate for a demo, not real security: `users.js` is public, so use throwaway passwords and never enter real company information. Each person's data is kept in their own browser and is not shared with other people.
